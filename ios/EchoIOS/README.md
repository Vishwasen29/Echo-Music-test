# Echo iOS scaffold

Generated by create_ios_scaffold.py.

This directory is intentionally a minimal SwiftUI iOS app so GitHub Actions/Xcode can build an iOS simulator artifact.

## Important limitation

This is **not** a port of the Android Echo app. The current repo is Android/Kotlin/Compose/Media3 based. iOS cannot compile Android `com.android.application`, Jetpack Compose Android UI, Android services, Media3, Room Android wiring, widgets, or Android resources.

To make a real iPhone version, the playback layer needs to be rewritten or shared through a cross-platform architecture, for example:

- SwiftUI/UIKit for iOS UI
- AVFoundation/AVPlayer for playback
- iOS-specific background audio setup
- iOS equivalents for storage, networking, artwork, playlists, and auth flows
- Shared Kotlin Multiplatform modules only where the code is actually platform-independent

## Local build command

```bash
xcodebuild \
  -project ios/EchoIOS.xcodeproj \
  -scheme EchoIOS \
  -configuration Debug \
  -sdk iphonesimulator \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath build/ios/DerivedData \
  CODE_SIGNING_ALLOWED=NO \
  clean build
```
